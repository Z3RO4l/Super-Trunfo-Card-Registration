# Super-Trunfo-Card-Registration

**Project Overview**

The purpose of the code I created was to integrate and compare data from different cities using proposed X factors. The project was assigned as part of a college challenge and was intended to help me develop the project while testing my programming skills at the start of the proposed projects. The challenge turned out to be an excellent opportunity to develop and test my skills. I learned a great deal throughout the process, explored new technologies, and further improved my knowledge of the languages I used.

------------------------------------------------------------------------------------------------------------

**Skills and Programming Languages**

Since this was one of my first projects and a starting point for developing and improving my skills, I built it entirely in C++.
